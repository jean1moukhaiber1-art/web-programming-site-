History of the World Wide Web

Home | Internet | Web

Introduction

The World Wide Web was created by Tim Berners-Lee at CERN. It allows people to access and connect information using technologies such as HTML, HTTP and URLs.

The Web is different from the Internet. The Internet is the network, while the Web is a service that uses the Internet.

Web Timeline

1989 : Web Proposal

Tim Berners-Lee proposed a system for sharing information using hypertext at CERN.

Source: CERN

1990 : First Web Browser and Server

Tim Berners-Lee created the first Web server and the first browser, called WorldWideWeb.

Source: CERN

1991 : First Website

The first website was created at CERN at info.cern.ch. It explained the World Wide Web.

Source: CERN

1993 : Mosaic Browser

The Mosaic browser was released by NCSA. It helped make Web browsing easier and contributed to the growth of the Web.

Source: Computer History Museum

1993 : Web Software Becomes Free

CERN released the Web software freely. This helped other people and organizations use and develop the Web.

Source: CERN

1994 : W3C

Tim Berners-Lee established the World Wide Web Consortium (W3C). It helps develop Web standards.

Source: W3C

1997 : HTML 3.2

HTML 3.2 became a W3C Recommendation and helped standardize common HTML features.

Source: W3C

Key Web Technologies

HTML

HTML is used to structure content on Web pages.

HTTP

HTTP allows Web browsers and servers to communicate.

URL

A URL identifies the location of a resource on the Web.
