History of the World Wide Web

The World Wide Web is a system that allows people to access and share information through the Internet.

Introduction

The World Wide Web was created by Tim Berners-Lee while working at CERN. He proposed the idea in 1989 to make it easier for researchers to share information.

The Web is not the same as the Internet. The Internet is the network that connects computers, while the Web is a service that uses this network to provide websites and information.

Web Timeline

1989 — Web Proposal

Tim Berners-Lee proposed a system for sharing information between researchers at CERN using hypertext and links.

Source: W3C

1990 — First Browser and Server

Berners-Lee developed the first Web browser and Web server. He also worked on the basic technologies needed for the Web.

Source: CERN

1991 — First Website

The first website was created at CERN. It explained the World Wide Web project and how people could use it.

Source: CERN

1993 — Web Growth

Graphical browsers such as Mosaic helped make the Web easier to use. In the same year, CERN released the Web software into the public domain, helping it spread.

Source: CERN

1994 — W3C Founded

Tim Berners-Lee founded the World Wide Web Consortium (W3C). It works on Web standards that help different browsers and websites work together.

Source: W3C

1990s — The Web Becomes Popular

During the 1990s, more businesses, universities, and individuals started creating websites. Images, forms, and other features made websites more useful and interesting.

2000s — More Interactive Websites

Websites became more interactive during the 2000s. CSS improved page design, while JavaScript allowed websites to respond to user actions.

Source: MDN Web Docs

2010s — Mobile Web

Smartphones and tablets changed the way people used the Web. Websites started using responsive design so that they could work on different screen sizes.

Web applications also became much more common.

2020s — The Modern Web

Today, websites can do much more than display information. People use the Web for communication, education, shopping, entertainment, work, and many online services.

Modern Web technologies also allow websites to behave more like applications and interact with different online services.

Key Web Technologies

HTML

HTML gives a Web page its structure. It is used for headings, paragraphs, links, images, lists, and other page elements.

HTTP

HTTP is used for communication between a Web browser and a Web server.

URLs

A URL identifies the location of a resource on the Web, such as a Web page or an image.

CSS

CSS controls the appearance and layout of Web pages, including fonts, spacing, and positioning.

JavaScript

JavaScript adds interaction to websites. It can respond to user actions and change content on a page.

The Web Today

The Web has changed a lot since the first website was created. Early websites were simple, but today's websites can include videos, maps, online applications, and many interactive features.

Even with all these changes, the basic idea is still the same: people can publish information and connect it through links using common Web technologies.
