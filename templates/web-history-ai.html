History of the World Wide Web

The World Wide Web is a system of interconnected information resources that was created on top of the Internet.

Introduction

The World Wide Web was invented by British computer scientist Tim Berners-Lee while he was working at CERN in Switzerland. He proposed the Web in 1989 as a way to improve information sharing between researchers.

The Web combined several ideas, including hypertext, computer networks, documents and browsers. It allowed users to move between connected information resources through hyperlinks.

The Web should not be confused with the Internet. The Internet is the underlying global network infrastructure, while the Web is an information system that operates using that network.

World Wide Web Timeline

1989 — Tim Berners-Lee Proposes the Web

Tim Berners-Lee wrote the first proposal for the World Wide Web while working at CERN.

His objective was to create a system that could make information easier to share between researchers working in different locations.

November 1990 — WorldWideWeb Proposal

Tim Berners-Lee and Robert Cailliau formalized the proposal for a hypertext project called WorldWideWeb.

The proposal described a system in which hypertext documents could be accessed using browsers and connected through links.

October 1990 — First Web Server and Browser

By the end of 1990, Berners-Lee had developed the first Web server and the first Web browser at CERN.

The original browser was called WorldWideWeb and was developed on a NeXT computer.

1990 — Early Web Technologies

Berners-Lee developed the basic technologies that made the Web possible, including HTML for describing documents, HTTP for communication, and URI-based addressing for identifying resources.

These technologies formed an important foundation for the Web as it developed.

1991 — Web Software Released at CERN

In 1991, the World Wide Web software became available to CERN colleagues. Later that year, Berners-Lee announced the software on Internet newsgroups.

This helped researchers outside CERN discover the Web and begin using and developing it.

December 1991 — First Web Server in the United States

The first Web server in the United States was established at the Stanford Linear Accelerator Center, known as SLAC.

Paul Kunz and Louise Addis helped bring the server online, extending the Web beyond CERN.

1991 — The First Website

The first website and Web server used the address info.cern.ch.

The first website described the World Wide Web project, explained hypertext, and provided information about how Web servers could be created.

1992 — Line-Mode Browser

A simpler line-mode browser was developed to make the Web available on more types of computers.

Nicola Pellow worked on the line-mode browser while at CERN. Unlike the original NeXT browser, it was designed to work on a wider range of systems.

Early 1993 — Mosaic Browser

The National Center for Supercomputing Applications, or NCSA, released an early version of the Mosaic browser.

Mosaic provided a more user-friendly graphical browsing experience and helped make the Web more accessible on popular computer systems.

30 April 1993 — CERN Releases Web Software

CERN placed the World Wide Web software in the public domain and made it available on a royalty-free basis.

This decision helped other people and organizations use, develop and distribute Web technology without having to pay licensing fees.

Late 1993 — Rapid Web Growth

The number of Web servers increased rapidly. CERN reports that by late 1993 there were more than 500 known Web servers.

The increasing availability of browsers and servers helped transform the Web from a research project into a growing global information system.

May 1994 — First International WWW Conference

The first International World Wide Web Conference was held at CERN in May 1994.

The conference brought together researchers, developers and users interested in the rapidly developing Web.

October 1994 — W3C Is Founded

Tim Berners-Lee founded the World Wide Web Consortium, known as W3C, at MIT in October 1994.

CERN, MIT, DARPA and the European Commission supported the creation of the organization.

W3C was created to help coordinate Web technologies and encourage common standards and interoperability.

1995 — HTML 2.0

HTML 2.0 provided a formal specification for important features of HTML and helped establish a common foundation for Web documents.

14 January 1997 — HTML 3.2

W3C issued HTML 3.2 as a Recommendation in January 1997.

It included widely used features such as tables, applets, images and other capabilities that had become common on the Web.

18 December 1997 — HTML 4.0

W3C issued HTML 4.0 as a Recommendation in December 1997.

HTML 4.0 introduced improvements involving forms, tables, scripting, style sheets, accessibility and international support.

Important Web Technologies

HTML

HTML stands for HyperText Markup Language. It is used to structure information in Web documents and create elements such as headings, paragraphs, lists and hyperlinks.

HTTP

HTTP stands for HyperText Transfer Protocol. It provides rules for communication between Web clients and Web servers.

URLs and URIs

Web resources need identifiers so that they can be located and referenced. The early Web included URI-based addressing, which became an important part of Web navigation.

Web Browsers

A Web browser is software that allows users to access and interact with Web resources. The original WorldWideWeb browser was created by Tim Berners-Lee.

Web Servers

A Web server provides Web resources to clients. The first Web server was created by Tim Berners-Lee at CERN.

Web Standards

Web standards provide common technical rules that help browsers, servers and websites work together.

The World Wide Web Consortium has played an important role in coordinating Web standards since its creation in 1994.
